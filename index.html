Fail-Closed Agent Isolation

Autonomous agents execute strictly in requestAgentAction mode. Any direct database or canvas write attempt triggers ERR_AGENT_DIRECT_MUTATION_PROHIBITED prior to storage I/O and logs negative audit evidence.

Modality Equivalence

Voice transcripts, chat prompts, and manual pointer gestures all compile into the exact same typed action schema. Natural language never bypasses governance checks enforced on human operators.

Model Replaceability

Foundation models are treated as swappable advisory plugins behind a deterministic reducer—preventing model drift from corrupting GxP, financial, editorial, or statutory records.
